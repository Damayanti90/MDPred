MDPred

Here, we predict GO and pathway associations related to Dipeptidyl peptidase-4 inhibitors (gliptins) leading to deriving  their multifunctionality. 


Instructions for execution

1. download and unzip full_run_1.zip and full_run_2.zip

2. Place all the files in both unzipped folders into another single folder

3. set up the environment using environment.yml

4. Execute .py files in the following order:


     (i) a_fv_formation_i.py
   
     (ii) b_ID_formation.py
   
     (iii) c_fv_formation_ii.py

     (iv)  d_xgboost_link_classification.py

     (v)   e_lightGBM_link_classification.py

     (vi)  f_clustering_preparation.py

     (vii)  g_clustering.py

     (viii)   h_pcos_pathway.py

     (ix)  i_pcos_go.py








For a quick start:

1. download and unzip quick_run_upload.zip

2. set up the environment using environment.yml inside quick_run_upload folder

3. Execute .py files in the following order-
   
       i. d_xgboost_link_classification.py
   
       ii.  e_lightGBM_link_classification.py
